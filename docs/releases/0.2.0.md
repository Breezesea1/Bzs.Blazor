# Bzs.Blazor 0.2.0

This feature release adds the productivity-oriented component wave that builds
toward a typed DataGrid while retaining static SSR, all interactive render
modes, localization, accessibility, CSP, trimming, and WebAssembly AOT support.

## Highlights

- Adds one internal anchored-overlay implementation shared by controlled
  popovers, accessible tooltips, command menus, and context menus without
  exposing browser coordinates or adapters publicly.
- Adds composable navigation, breadcrumbs, controlled pagination, skeletons,
  badges, chips, and avatars for data-heavy application surfaces.
- Adds provider-backed autocomplete with debounce, cancellation, stale-result
  suppression, templates, and EditForm integration.
- Adds EditForm-integrated file selection with controlled browser-file state,
  count and size validation, and consumer-owned progress presentation.
- Adds a typed DataGrid for in-memory and asynchronous provider data, including
  column templates, controlled sorting, filtering, paging, page size,
  selection, loading, empty, retryable error, and known- or unknown-total
  workflows.
- Adds a shared Productivity Demo for Static SSR, Interactive Server,
  Interactive WebAssembly, Interactive Auto, and standalone WebAssembly, plus
  package-only consumer coverage for the new workflows.

## New Public Contracts

- Anchored interaction: `BzsPopover`, `BzsTooltip`, `BzsMenu`, `BzsMenuItem`,
  `BzsContextMenu`, and their placement and dismissal contracts.
- Navigation: `BzsNavMenu`, `BzsNavItem`, `BzsBreadcrumbs`,
  `BzsBreadcrumbItem`, and `BzsPagination`.
- Status: `BzsSkeleton`, `BzsBadge`, `BzsChip`, and `BzsAvatar`.
- Asynchronous input: `BzsAutocomplete<TValue>`,
  `IBzsAutocompleteProvider<TValue>`, `BzsAutocompleteOption<TValue>`, and
  `BzsFileUpload`.
- Tabular data: `BzsDataGrid<TItem>`, `BzsDataGridColumn<TItem>`,
  `IBzsDataGridProvider<TItem>`, `BzsDataGridRequest`,
  `BzsDataGridResult<TItem>`, sort, selection, and typed filter contracts.

## Deliberately Deferred

The first DataGrid release does not include cell editing, grouping, hierarchy,
column drag-and-drop, frozen columns, virtualization, export, or persisted
preferences. Nested menu submenus and autocomplete free-text values are also
deferred. File upload remains responsible for selection, metadata, validation,
and progress presentation; consumers continue to own transport, storage,
authentication, retry, resumable upload, and security scanning.

TreeView, Accordion, Stepper, time/range pickers, Slider, Rating, Splitter,
Timeline, and DropZone remain outside this release. Charts, Scheduler, Gantt,
Spreadsheet, rich-text editing, maps, media viewers, AI/chat modules, and
third-party UI runtime dependencies are also deferred. The release does not
introduce a public generic portal manager or browser-positioning adapter, nor
replacement wrappers for `BzsSurface`, `BzsButton`, native `EditForm`, or other
already-covered behavior.

## Breaking Changes

None to previously shipped public contracts. The new APIs are additive.

## Publication

This release candidate was superseded by 0.2.1 before NuGet publication. The
0.2.1 package is the first published package containing this component wave.
