# Bzs.Blazor 0.1.8

This patch release adds a reusable neumorphic segmented radio-group appearance
and uses it for reliable English and Simplified Chinese switching in the Demo.

## Highlights

- Adds the optional `BzsRadioGroupVariant.Segmented` appearance while preserving
  the existing `Standard` behavior as the default.
- Uses native radio inputs, strongly typed values, EditForm integration, and
  existing accessibility relationships for the segmented control.
- Builds the segmented treatment entirely from the library's semantic inset,
  raised, focus, disabled, motion, and forced-colors tokens.
- Replaces the Demo-only language links with a shared component implemented
  through the public `BzsRadioGroup<string>` API.
- Runs the server Demo switch as an Interactive Auto island while retaining the
  static WebAssembly root reload required by GitHub Pages culture resources.
- Preserves the selected culture across Forms, Feedback, Overview, and other
  Demo navigation routes.
- Expands unit, browser, accessibility, standalone WebAssembly, and desktop and
  mobile visual regression coverage for the new control.

## Breaking Changes

None. `BzsRadioGroupVariant.Standard` remains the default, and existing radio
groups retain their native form, validation, read-only, and keyboard behavior.

## Publication

Pushing this release preparation commit to `main` starts CI. A successful CI
run triggers the GitHub Pages demo deployment. NuGet publication remains a
separate guarded action and starts only when the strict `v0.1.8` tag is pushed.
