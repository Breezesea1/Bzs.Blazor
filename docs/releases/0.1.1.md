# Bzs.Blazor 0.1.1

This patch release refreshes the Demo hosts and built-in theme visuals while
keeping the public component API and hosting contracts unchanged.

## Highlights

- Reworked the Aspire and GitHub Pages Demo shells around the compact,
  neutral neumorphic language used by the Auth and Savvy applications.
- Centralized the shared Demo catalog stylesheet so the server and standalone
  WebAssembly hosts use the same navigation, responsive, and surface rules.
- Refined the built-in light and dark semantic theme tokens, including raised
  and inset depth, neutral controls, and higher-contrast input boundaries.
- Added a component-group overview to both Demo hosts and refreshed the light
  and dark desktop/mobile visual regression baselines.
- Added a theme contract test for WCAG non-text contrast on enabled input
  boundaries.

## Breaking Changes

None. Public component APIs, render-mode support, static SSR behavior, and the
no-third-party-runtime-dependency boundary remain unchanged.

## Publication

This version is published through the GitHub Actions workflow started by the
annotated `v0.1.1` tag. Install it with:

```text
dotnet add package Bzs.Blazor --version 0.1.1
```

Package symbols use Source Link to map sources to the
[GitHub repository](https://github.com/Breezesea1/Bzs.Blazor). Publication uses
the controlled tag-push authorization and the protected `nuget-production`
environment with NuGet.org Trusted Publishing.
