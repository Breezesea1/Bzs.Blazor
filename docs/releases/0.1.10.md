# Bzs.Blazor 0.1.10

This patch release expands the layout system into a complete application frame
and updates both Demo hosts to exercise the public components directly.

## Highlights

- Adds `BzsAppShell`, `BzsAppBar`, `BzsNavigationDrawer`, and
  `BzsMainContent` for composing application-level navigation and content.
- Supports persistent, temporary, and responsive navigation drawers anchored
  to either logical edge, with controlled open-state callbacks and backdrop
  behavior.
- Coordinates app-bar and main-content offsets through CSS while preserving
  useful static SSR markup across Server, WebAssembly, and Auto rendering.
- Keeps navigation above the app bar, removes structural borders, and exposes
  semantic surface and color options through the existing theme tokens.
- Rebuilds the Aspire-hosted and standalone WebAssembly Demo shells with the
  public Bzs layout components, shared navigation icons, and restrained
  neumorphic theme colors.
- Adds responsive host behavior for desktop preference persistence, mobile
  backdrop dismissal, Escape handling, focus containment, focus restoration,
  and exact `48rem` breakpoint transitions.
- Uses `BzsButton` for the Demo navigation controls with distinct raised and
  pressed neumorphic treatments for open and close states.
- Extends unit, browser, accessibility, overlay, standalone WebAssembly, and
  visual-regression coverage for the new layout surface.

## Breaking Changes

None. This release adds new public components and layout option types without
changing existing component defaults or behavior.

## Publication

Pushing this release preparation commit to `main` starts CI. A successful CI
run triggers the GitHub Pages demo deployment. NuGet publication remains a
separate guarded action and starts only when the strict `v0.1.10` tag is pushed.
