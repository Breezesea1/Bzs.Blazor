# Bzs.Blazor 0.1.5

This patch release expands the foundational form and feedback controls, adds
searchable single and multi-select experiences, and sharpens the restrained
neumorphic visual system.

## Highlights

- Adds `BzsEmptyState` with composable icon, description, and action content.
- Adds EditForm-integrated `BzsToggle` and strongly typed `BzsRadioGroup<TValue>`
  controls with native switch and radio semantics.
- Enhances `BzsSelect<TValue>` with a searchable custom combobox and adds
  `BzsMultiSelect<TValue>` with search, select-all, invert, and clear actions.
- Preserves editable native select markup during static SSR and native required
  constraint validation after interactive enhancement.
- Adds localized English and Simplified Chinese text for library-owned select
  placeholders, empty states, selection summaries, and bulk actions.
- Closes open selects after outside pointer interactions, skips disabled options
  during keyboard navigation, and keeps transformed-container panels aligned.
- Removes visible borders from buttons and semantic surfaces, strengthens the
  compact depth treatment, and reduces overly bright light-theme highlights.
- Updates the Demo catalog, package-consumer checks, browser interaction tests,
  and approved light/dark desktop/mobile visual baselines.

## Breaking Changes

None. Existing public component contracts, render-mode support, static SSR
behavior, and the no-third-party-runtime-dependency boundary remain intact.

## Publication

This version is published through the GitHub Actions workflow started by the
annotated `v0.1.5` tag. Install it with:

```text
dotnet add package Bzs.Blazor --version 0.1.5
```

Package symbols use Source Link to map sources to the
[GitHub repository](https://github.com/Breezesea1/Bzs.Blazor). Publication uses
the controlled tag-push authorization and the protected `nuget-production`
environment with NuGet.org Trusted Publishing.
