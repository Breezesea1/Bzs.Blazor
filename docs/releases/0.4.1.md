# Bzs.Blazor 0.4.1

This patch release completes the DataGrid core expected of an established grid
library without breaking previously published APIs.

## Highlights

- Adds client-side filtering and global search to `Items` mode through
  `ClientFiltering` and `SearchText`, with `NotContains`, `IsEmpty`, and
  `IsNotEmpty` text operators and a multi-value `Choice` filter kind.
- Adds multi-column sorting through `Sorts`/`SortsChanged` with header
  precedence badges, while the single-column `Sort` contract is unchanged.
- Adds per-column `Align`, `Width`, `MinWidth`, `Sticky`, `Visible`, `Hideable`,
  and `Resizable` options, a toolbar column chooser, and footer `Aggregate` and
  `FooterTemplate` summaries that cover every queried row.
- Adds `Density`, `Striped`, `Bordered`, and `StickyHeader` presentation,
  expandable `DetailTemplate` rows, and row activation through `RowClick`.
- Adds pointer and keyboard column resizing that applies widths through the
  CSSOM on `col` elements, keeping server-rendered markup free of inline
  styles under `style-src 'self'`.

## Public API

- Adds the grid search, multi-sort, hidden-column, expansion, row-activation,
  density, and column-resize parameters and callbacks.
- Adds the column alignment, sizing, visibility, stickiness, aggregate, and
  footer-template parameters.
- Adds `BzsDataGridChoiceFilter`, the new text operators, the request
  `Sorts`/`SearchText` fields, and the supporting enum and event-argument
  types.

## Reliability And Delivery

- Fixes the DataGrid stylesheet reference to the undefined
  `--bzs-primary-contrast` token, which left active sort and filter buttons
  without a foreground color; the grid now uses `--bzs-on-primary`.
- Client filtering that narrows results below the controlled page clamps the
  rendered page instead of throwing while the consumer catches up.
- Focusable column-resize separators carry the ARIA value attributes the axe
  gate requires.
- Raises the measured package budgets to 328 KiB for the runtime package and
  176 KiB for symbols. Local verification measured 311,610 and 172,961 bytes
  respectively after recompression.

## Compatibility

Existing routes and supported render modes remain compatible. The new runtime
package contracts are additive, all new state stays controlled, and passive
markup remains useful under Static SSR.

## Publication

Pushing the release commit to `main` starts CI and the dependent GitHub Pages
deployment. After the exact-SHA CI run succeeds, pushing the strict `v0.4.1`
tag starts the guarded NuGet workflow. Publication remains subject to the
protected `nuget-production` environment.
