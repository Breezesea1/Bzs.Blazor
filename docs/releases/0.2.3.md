# Bzs.Blazor 0.2.3

This patch improves the bilingual Demo and release experience without changing
the runtime package's public API surface.

## Highlights

- Makes Simplified Chinese the default Demo culture and localizes the shared
  catalog shell while preserving the selected culture across navigation.
- Adds a persistent light, dark, and system theme switch shared by the Demo
  hosts.
- Rebuilds the landing page as a responsive, shared bilingual product page with
  installation guidance, component previews, and the latest release summary.
- Adds the Bzs.Blazor logo and favicon assets across the Demo and its release
  presentation.

## Fixes

- Keeps the language switcher visually consistent while static SSR fallback
  markup is displayed before interactive rendering, including when JavaScript
  is unavailable.
- Covers the fallback language control with a JavaScript-disabled browser test.
- Restores the published 0.2.2 anchored-overlay notes to the Demo release
  archive.
- Corrects the DatePicker keyboard test expectation for month-end clamping:
  moving from August 31 to September and back correctly lands on August 30.

## Compatibility

There are no breaking changes and no new runtime APIs in this release. The
package keeps its existing dependency boundary and supports Static SSR,
Interactive Server, Interactive WebAssembly, Interactive Auto, and standalone
WebAssembly.

## Publication

Pushing the release commit to `main` starts CI and the dependent GitHub Pages
deployment. After the exact-SHA CI run succeeds, pushing the strict `v0.2.3`
tag starts the guarded NuGet workflow. Publication remains subject to the
protected `nuget-production` environment.
