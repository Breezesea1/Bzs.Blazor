# Bzs.Blazor 0.1.3

This patch release refreshes the built-in light and dark visual system while
preserving the existing public component API and render-mode behavior.

## Highlights

- Improves light and dark surface separation, input boundaries, and semantic
  depth while keeping dense controls comparatively restrained.
- Keeps the public `BzsThemes` records exactly aligned with the built-in static
  CSS, including colors and shadows used by runtime custom themes.
- Adds contract coverage that prevents static theme tokens and strongly typed
  defaults from drifting apart again.
- Stabilizes visual regression fixtures so baseline updates contain only
  intentional visual changes.

## Breaking Changes

None. Public component APIs, render-mode support, static SSR behavior, and the
no-third-party-runtime-dependency boundary remain unchanged.

## Publication

This version is published through the GitHub Actions workflow started by the
annotated `v0.1.3` tag. Install it with:

```text
dotnet add package Bzs.Blazor --version 0.1.3
```

Package symbols use Source Link to map sources to the
[GitHub repository](https://github.com/Breezesea1/Bzs.Blazor). Publication uses
the controlled tag-push authorization and the protected `nuget-production`
environment with NuGet.org Trusted Publishing.
