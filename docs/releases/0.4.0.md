# Bzs.Blazor 0.4.0

This feature release expands productivity workflows, navigation, identity, and
the shared Demo Catalog without breaking previously published APIs.

## Highlights

- Adds richer DataGrid toolbar, filtering, result-summary, retry, and controlled
  workflow presentations.
- Adds pointer and keyboard resizing to `BzsNavigationDrawer`, including shell
  width synchronization and responsive constraints.
- Extends `BzsAvatar` with visible identity names and optional trailing action
  composition.
- Centralizes Demo Catalog destination identity, host availability, localized
  runtime presentation, culture preservation, and base-path-aware URLs.

## Public API

- Adds the resizable NavigationDrawer parameters and resize-completion callback.
- Adds Avatar identity and action composition parameters.
- Adds DataGrid productivity options introduced since 0.3.0.

## Reliability And Delivery

- Keeps cancellation, stale-result suppression, retry, stable sorting, focus,
  and JavaScript lifecycle invariants covered by focused tests.
- Uses accessible roles, names, visible state, URLs, and stable semantic hooks as
  the primary test interface.
- Keeps full and standalone Demo hosts on one capability-filtered destination
  and runtime presentation.
- Raises the measured package budgets to 296 KiB for the runtime package and
  172 KiB for symbols. CI measured 286,132 and 165,145 bytes respectively;
  the growth comes from the larger runtime DLL, drawer interop, styles, resources,
  and API documentation. The WASM AOT framework budget is unchanged.

## Compatibility

Existing routes and supported render modes remain compatible. The new runtime
package contracts are additive, and passive markup remains useful under Static
SSR.

## Publication

Pushing the release commit to `main` starts CI and the dependent GitHub Pages
deployment. After the exact-SHA CI run succeeds, pushing the strict `v0.4.0`
tag starts the guarded NuGet workflow. Publication remains subject to the
protected `nuget-production` environment.
