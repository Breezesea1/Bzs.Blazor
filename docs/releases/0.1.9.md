# Bzs.Blazor 0.1.9

This patch release adds reusable CSS-only layout primitives and exposes them
through both the Aspire-hosted Demo and the standalone GitHub Pages catalog.

## Highlights

- Adds `BzsContainer` with responsive fixed widths, optional gutters, and
  strongly typed maximum-width options.
- Adds a twelve-column `BzsGrid` and `BzsGridItem` with validated `Xs` through
  `Xxl` responsive spans.
- Adds `BzsStack`, `BzsSpacer`, and `BzsDivider` for token-driven flex layouts,
  flexible space distribution, and horizontal or vertical separation.
- Keeps the components CSS-only and JavaScript-free so their passive markup is
  useful during static SSR and across Server, WebAssembly, and Auto rendering.
- Promotes shared layout-spacing values into the global token contract while
  retaining component structure in isolated CSS.
- Covers responsive grid geometry, spacer distribution, divider stretching,
  absolute inset behavior, common attributes, validation, and accessibility
  semantics through unit and browser tests.
- Adds the Layout catalog route and navigation to both Demo hosts, including
  the GitHub Pages WebAssembly site.

## Breaking Changes

None. This release adds new public components and layout option types without
changing existing component defaults or behavior.

## Publication

Pushing this release preparation commit to `main` starts CI. A successful CI
run triggers the GitHub Pages demo deployment. NuGet publication remains a
separate guarded action and starts only when the strict `v0.1.9` tag is pushed.
