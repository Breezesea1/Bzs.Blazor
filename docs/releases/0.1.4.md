# Bzs.Blazor 0.1.4

This patch release increases the default semantic corner radii and removes
duplicated radius values from the Demo styling.

## Highlights

- Increases the built-in control, container, and overlay radius tokens from
  `0.5rem` to `0.625rem` for a slightly softer visual hierarchy.
- Keeps the strongly typed `BzsThemeShape` defaults aligned with the external
  static CSS contract.
- Replaces Demo-specific hardcoded corner radii with semantic control,
  container, overlay, compact-marker, and round-indicator tokens.
- Rebinds Demo radius aliases inside theme-provider scopes so runtime custom
  shape values remain visually consistent with surrounding Demo content.
- Refreshes the four approved light/dark desktop/mobile visual baselines.

## Breaking Changes

None. Public component APIs, render-mode support, static SSR behavior, and the
no-third-party-runtime-dependency boundary remain unchanged.

## Publication

This version is published through the GitHub Actions workflow started by the
annotated `v0.1.4` tag. Install it with:

```text
dotnet add package Bzs.Blazor --version 0.1.4
```

Package symbols use Source Link to map sources to the
[GitHub repository](https://github.com/Breezesea1/Bzs.Blazor). Publication uses
the controlled tag-push authorization and the protected `nuget-production`
environment with NuGet.org Trusted Publishing.
