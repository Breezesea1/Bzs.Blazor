# Bzs.Blazor 0.1.0

The first local release establishes the package, theme system, component
foundation, native form controls, feedback services, overlays, tabs,
localization, and the render-mode Demo.

## Highlights

- Compact neumorphic Light, Dark, and System themes.
- Interactive Server, Interactive WebAssembly, Interactive Auto, and useful
  static SSR markup.
- Native `EditForm` integration for text, textarea, number, date, checkbox,
  and select controls.
- Scoped toast and component-typed dialog services with explicit results.
- Keyboard, accessibility, browser-matrix, visual, trimming, and WASM AOT
  release gates.

## Breaking Changes

None. This is the initial `0.1.0` package.

## Known Release Metadata Limitation

Source Link requires a real repository URL and commit. A local package built
before this repository has a configured Git remote cannot contain resolvable
remote source links. The release verifier reports that condition explicitly
and still verifies deterministic build settings, portable symbols, and
embedded source metadata without inventing a repository URL.
