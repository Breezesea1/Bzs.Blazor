# Bzs.Blazor 0.1.0

The first release establishes the package, theme system, component foundation,
native form controls, feedback services, overlays, tabs, localization, and the
render-mode Demo.

## Highlights

- Compact neumorphic Light, Dark, and System themes.
- Interactive Server, Interactive WebAssembly, Interactive Auto, and useful
  static SSR markup.
- Native `EditForm` integration for text, textarea, number, date, checkbox,
  and select controls.
- Scoped toast and component-typed dialog services with explicit results.
- Keyboard, accessibility, browser-matrix, visual, trimming, and WASM AOT
  release gates.

## Breaking Changes

None. This is the initial `0.1.0` package.

## Publication

This version is published on
[nuget.org](https://www.nuget.org/packages/Bzs.Blazor/0.1.0) and can be
installed with:

```text
dotnet add package Bzs.Blazor --version 0.1.0
```

Package symbols use Source Link to map sources to the
[GitHub repository](https://github.com/Breezesea1/Bzs.Blazor). A strict SemVer
tag such as `v0.1.0` starts the GitHub Actions release workflow. A controlled
tag push is the final publication authorization; the workflow then requires
Ubuntu and Windows release gates before OIDC publication through the
`nuget-production` environment.
