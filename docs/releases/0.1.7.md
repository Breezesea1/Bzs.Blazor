# Bzs.Blazor 0.1.7

This patch release refines the custom date picker with explicit Chinese
localization, neumorphic period controls, and more complete keyboard behavior.

## Highlights

- Adds an optional `Culture` parameter so consumers can localize date formats,
  month and weekday names, actions, validation messages, and accessible labels
  without changing the host application's ambient culture.
- Uses the existing Simplified Chinese resource set in the Demo date picker,
  including Chinese month, weekday, navigation, Today, and Clear text.
- Replaces native month and year selects with compact ARIA combobox/listbox
  controls that avoid operating-system menus and keep the active option visible.
- Aligns the calendar, navigation, period menus, selected dates, and actions with
  the library's existing neumorphic surfaces, inset states, shadows, and themes.
- Adds Arrow, Home, End, PageUp, PageDown, Enter, Space, Escape, Tab, and
  localized typeahead behavior for the month and year controls.
- Preserves pointer-based panel placement, short-viewport scrolling, Popover
  top-layer behavior, static SSR native fallback, and all supported date types.
- Makes explicit-culture parsing deterministic while retaining ISO
  `yyyy-MM-dd` input for static SSR form posts.
- Expands unit, browser, accessibility, containment, and keyboard regression
  coverage without coupling tests to internal option identifiers.

## Breaking Changes

None. The new `Culture` parameter is optional, and existing consumers continue
to follow the current culture and UI culture when it is not supplied.

## Publication

Pushing this release preparation commit to `main` starts CI. A successful CI
run triggers the GitHub Pages demo deployment. NuGet publication remains a
separate guarded action and starts only when the annotated `v0.1.7` tag is
pushed.
