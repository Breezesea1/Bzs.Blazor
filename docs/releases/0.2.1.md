# Bzs.Blazor 0.2.1

This patch finalizes the 0.2 productivity component wave and hardens its
accessibility, keyboard interaction, release announcement experience, and
JavaScript lifecycle behavior. It is the first published package containing
the APIs prepared in the 0.2.0 release candidate.

## Highlights

- Adds the anchored interaction, navigation, pagination, status, autocomplete,
  file selection, and typed DataGrid modules prepared in 0.2.0.
- Localizes the default Breadcrumb landmark name and formats Badge counts with
  the active culture.
- Prevents Menu Arrow, Home, and End navigation from scrolling the content
  region while keeping focus movement predictable.
- Makes scrollable main content keyboard reachable by default while preserving
  consumer `tabindex` overrides.
- Adds a Demo-local What's new entry with an unread badge, accessible tooltip,
  explicit summary dialog, and localized long-form release archive.
- Makes announcement persistence and JavaScript module disposal degrade safely
  when browser storage or module loading is unavailable.

## Public Contracts

- Anchored interaction: `BzsPopover`, `BzsTooltip`, `BzsMenu`, `BzsMenuItem`,
  `BzsContextMenu`, and their placement and dismissal contracts.
- Navigation and status: `BzsNavMenu`, `BzsNavItem`, `BzsBreadcrumbs`,
  `BzsBreadcrumbItem`, `BzsPagination`, `BzsSkeleton`, `BzsBadge`, `BzsChip`,
  and `BzsAvatar`.
- Asynchronous input: `BzsAutocomplete<TValue>`,
  `IBzsAutocompleteProvider<TValue>`, `BzsAutocompleteOption<TValue>`, and
  `BzsFileUpload`.
- Tabular data: `BzsDataGrid<TItem>`, `BzsDataGridColumn<TItem>`,
  `IBzsDataGridProvider<TItem>`, `BzsDataGridRequest`,
  `BzsDataGridResult<TItem>`, and the related sorting, filtering, and selection
  contracts.

## Fixes

- Menu keyboard navigation suppresses the corresponding browser scroll action.
- The light information color meets WCAG AA text contrast on base surfaces.
- Breadcrumb and Badge defaults follow the active UI and numeric culture.
- The latest-release announcement is acknowledged independently from historical
  entries, and storage failures fall back to the current session.
- Failed announcement module imports are tolerated during asynchronous disposal.
- Unused Popover and Menu trigger references were removed.

## Compatibility

There are no breaking changes to previously published APIs or to the public
contracts introduced in the 0.2.0 release candidate. The runtime package keeps
its dependency boundary and supports Static SSR, Interactive Server,
Interactive WebAssembly, Interactive Auto, and standalone WebAssembly.

## Publication

Pushing the release commit to `main` starts CI and the dependent GitHub Pages
deployment. After the exact-SHA CI run succeeds, pushing the strict `v0.2.1`
tag starts the guarded NuGet workflow. Publication remains subject to the
protected `nuget-production` environment.
