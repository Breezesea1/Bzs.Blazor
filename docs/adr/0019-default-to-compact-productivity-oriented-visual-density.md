# Default to compact productivity-oriented visual density

Bzs.Blazor defaults to a quiet, desktop-first productivity-tool density with mobile usability, compact 34-36px controls, restrained 6-8px radii, neutral cool-light and charcoal-dark surfaces, a balanced accent and semantic palette, and comparatively flat dense lists and menus. Compact is the default density, Comfortable is available for touch or lower-density experiences, and no spacious marketing-oriented density is included.
