# Reimplement reference behavior behind the new library contracts

CoreApi and CoreApi.Client remain read-only reference applications during the first Bzs.Blazor release. Proven behavior, interaction rules, algorithms, and test scenarios may be reimplemented behind the new library's naming, theme, accessibility, and component interfaces, but application namespaces, domain models, Tailwind classes, Radzen types, host asset paths, build assumptions, and compatibility aliases are not copied into the package; adoption by Dy3dTasks is a later migration.
