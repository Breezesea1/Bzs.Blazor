# Own the date picker period menus in a state module

The date picker's month and year menus keep their open state, active option, and typeahead buffer in an internal state module whose interface is "a key or pointer activation in, the action the owner must perform out"; the component moves the calendar view, renders the options, and scrolls the active one into sight. The calendar's pure date arithmetic had already been extracted and directly tested, which left the riskier surface — roughly 220 lines of keyboard and typeahead branching, including a repeated-letter cycle that applies to months but not years and a buffer that expires on a timeout — reachable only by rendering a calendar and driving its DOM. Behind an interface those branches become directly assertable, and the timeout is injectable rather than reading the ambient clock. This follows ADR-0032's option-list precedent: the two menus are one concept with two option sources, so they share one module rather than one being written twice, and the module stays internal because the public parameters and rendered markup do not change.
