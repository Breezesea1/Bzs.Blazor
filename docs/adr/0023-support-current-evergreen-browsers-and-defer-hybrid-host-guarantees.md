# Support current evergreen browsers and defer Hybrid host guarantees

Bzs.Blazor supports current stable Chrome, Edge, Firefox, Safari, iOS Safari, and Android Chrome, with automated Chromium, Firefox, WebKit, mobile-emulation, and Windows branded-browser gates. Internet Explorer, obsolete browsers, compatibility modes, and old embedded WebViews are unsupported; MAUI Blazor Hybrid and desktop shells remain best effort until dedicated smoke tests exist, while newer APIs such as Popover and CSS Anchor Positioning are progressive enhancements rather than required foundations.
