# Own the provider request lifecycle in one module

Provider-backed DataGrid state lives in an internal request-lifecycle module that owns which request is current, together with the accepted page, failure, and loading state derived from it; the component keeps its public parameters, builds requests from them, and renders a snapshot. Deciding "which request is current" had been split across two owners — a version counter inside the request coordinator and a structural request comparison inside the component — which could disagree, so concurrency and supersession could only be verified by rendering the whole component and inspecting its markup. Moving both decisions behind one interface makes them a single invariant and makes queueing, supersession, failure retention, and page correction directly assertable without a renderer. The coordinator becomes an internal detail of that module, responsible only for one provider call and its cancellation, and structural request equality moves to a shared helper so the component and the lifecycle compare requests the same way. Public parameters, events, and rendered behaviour are unchanged; ADR-0026's allowance for sharing cancellation and stale-result suppression once duplication is proven is what this consolidates.
