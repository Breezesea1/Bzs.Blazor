# Release under MIT and stabilize through local SemVer packages

The package, assembly, and root namespace use `Bzs.Blazor`, licensed under MIT and versioned with Semantic Versioning beginning at `0.1.0`; breaking public-interface changes remain allowed during 0.x but must be documented. Builds include package documentation, licenses and Lucide attribution, XML docs, Source Link, deterministic output, and symbols, and releases are first validated as local NuGet packages before any later decision to publish publicly.
