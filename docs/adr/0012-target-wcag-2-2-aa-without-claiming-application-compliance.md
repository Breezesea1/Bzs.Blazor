# Target WCAG 2.2 AA without claiming application compliance

Bzs.Blazor components and built-in light and dark themes will target WCAG 2.2 AA through contrast, keyboard operation, focus management, accessible form relationships, appropriate live regions, reduced-motion support, zoom resilience, and forced-colors degradation. Neumorphic shadows never carry meaning alone, and automated plus manual component verification supports this target, but the library does not claim that consumer applications are automatically compliant.
