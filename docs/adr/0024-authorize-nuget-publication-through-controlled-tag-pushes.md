# Authorize NuGet publication through controlled tag pushes

A controlled push of a strict `v<SemVer>` tag is the final human authorization to publish that version to NuGet.org; `nuget-production` does not add a required reviewer. This decision completes the public publication choice deferred by ADR 0017. The release workflow must keep strict tag/project-version equality, require the peeled tag commit to equal current `origin/main`, require a successful `main` push CI run for that exact SHA, retain Ubuntu and Windows release gates, use OIDC Trusted Publishing through the `nuget-production` environment, and preserve restricted tag creation and update permissions. The workflow enforces the commit and CI provenance checks before building release artifacts; the operator must wait for the exact-SHA `main` CI run to succeed before pushing a release tag.
