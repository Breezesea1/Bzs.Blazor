# Authorize NuGet publication through controlled tag pushes

A controlled push of a strict `v<SemVer>` tag is the final human authorization to publish that version to NuGet.org; `nuget-production` does not add a required reviewer. This decision completes the public publication choice deferred by ADR 0017. The release workflow must keep strict tag/project-version equality, Ubuntu and Windows release gates, OIDC Trusted Publishing, the `nuget-production` environment, and restricted tag creation and update permissions. Before pushing a release tag, the operator must verify that its peeled commit equals the intended release commit and current `origin/master`, and that CI succeeded for that exact SHA. The current workflow does not enforce those commit and CI checks, and repository evidence has not yet proven the effective GitHub tag ruleset, so these remain explicit release-process controls until independently enforced and verified.
